# NACA0012 BDF2 Restart-Validation Study

## Purpose

This document defines the numerical campaign required to validate the two-history BDF2 restart analysis developed in the mesh-to-mesh interpolation paper.

The study must distinguish:

1. the native difference between the source- and target-mesh trajectories;
2. the interpolation defects in the two BDF2 history states;
3. the exact residual forcing generated by those history defects;
4. the first converged target-mesh response;
5. the immediate and short-time aerodynamic response.

The **independently computed native target-mesh trajectory** is the reference for every transfer-induced quantity. Do not use the continuing source-mesh calculation as the reference, because that would mix interpolation error with the native source-target discretization difference.

The current steady NACA0012 case is sufficient for the first and most important validation stage. A weakly unsteady extension is defined later to test genuinely different defects at the two history levels.

---

## 1. Mathematical quantities to evaluate

For the target-mesh BDF2 residual, use the convention

\[
\Phi_B\!\left(U^{n+1};U^n,U^{n-1}\right)
=
\frac{1}{\Delta t}M_B
\left(
\frac{3}{2}U^{n+1}-2U^n+\frac{1}{2}U^{n-1}
\right)
+F_B(U^{n+1}),
\]

where:

- \(M_B\) is the target finite-volume mass/volume matrix;
- \(F_B\) is the target spatial residual;
- \(U^n\) and \(U^{n-1}\) are the two BDF2 history states.

Let the independently computed native target states be \(U_B^n\) and \(U_B^{n-1}\), and let the source states transferred onto the target mesh be

\[
\widehat U_B^n=\mathcal I_{AB}U_A^n,
\qquad
\widehat U_B^{n-1}=\mathcal I_{AB}U_A^{n-1}.
\]

Define the target-referenced history defects

\[
\epsilon^n=\widehat U_B^n-U_B^n,
\qquad
\epsilon^{n-1}=\widehat U_B^{n-1}-U_B^{n-1},
\]

and their BDF2 combination

\[
\eta^n=2\epsilon^n-\frac{1}{2}\epsilon^{n-1}.
\]

For the same trial state \(U_{B,0}^{n+1}\), the restarted-minus-native residual difference must satisfy the exact identity

\[
\Phi_B\!\left(U_{B,0}^{n+1};\widehat U_B^n,\widehat U_B^{n-1}\right)
-
\Phi_B\!\left(U_{B,0}^{n+1};U_B^n,U_B^{n-1}\right)
=
-\frac{1}{\Delta t}M_B\eta^n.
\]

After fully converging the first physical step, define the target-referenced response

\[
\delta^{n+1}
=
U_{B,\mathrm{restart}}^{n+1}
-
U_{B,\mathrm{native}}^{n+1}.
\]

These definitions must be used consistently in every script, CSV file, plot, and manuscript table.

---

## 2. Native steady solutions

### 2.1 Required calculations

Converge independently:

1. a steady solution \(U_A^\star\) on source mesh \(A\);
2. a steady solution \(U_B^\star\) on target mesh \(B\).

Use the physical and numerical settings already defined for the current NACA0012 case. Do not change Mach number, Reynolds number, angle of attack, turbulence/transition model, boundary conditions, reference quantities, force conventions, or spatial discretization between the two meshes.

### 2.2 Convergence requirements

The native solutions must be converged sufficiently that their remaining iterative noise is smaller than the transfer-induced response to be measured.

Record for both meshes:

- final residuals for every solved equation;
- lift, drag, and pitching moment over the final convergence window;
- maximum and RMS coefficient variation over that window;
- final restart files in the exact solver format.

The target steady state \(U_B^\star\) is the principal reference.

### 2.3 Native BDF2 noise-floor run

Before any transferred restart, run the target mesh for at least the same short physical-time window used for the restarted cases, with

\[
U_B^n=U_B^{n-1}=U_B^\star.
\]

Use the intended physical time step and BDF2 settings. This run defines:

- the native first-step state \(U_{B,\mathrm{native}}^{n+1}\);
- the native coefficient history;
- the numerical noise floor associated with incomplete steady convergence, dual-time convergence, and output precision.

All restarted cases must be compared with this native target run.

---

## 3. Generate transferred target states

For each interpolation method, transfer \(U_A^\star\) from mesh \(A\) to mesh \(B\):

- NN1;
- NN2;
- NN3;
- BAR2;
- BAR3;
- GP2;
- GP3.

Also run the global-conservation correction for the non-conservative methods. At minimum, include NN1+Global and BAR2+Global because these are the critical comparisons from the Riemann study. If computationally inexpensive, apply the correction to all NN and BAR orders.

Transfer the solver variables in the representation expected by the restart reader. Conserved fluid variables must remain consistent as a vector state; do not independently interpolate primitive variables and then reconstruct a different conservative state unless that is the solver's established restart procedure. Treat turbulence or transition variables using the solver's existing interpolation and admissibility rules, and report their norms separately from the conservative flow variables.

For the steady experiment, denote each transferred state by

\[
\widehat U_B^\star=\mathcal I_{AB}U_A^\star,
\qquad
\epsilon^\star=\widehat U_B^\star-U_B^\star.
\]

---

## 4. Core experiment: four steady mixed-history restarts

For every transfer method, construct the following target-mesh history pairs.

| Case ID | History at \(t^n\) | History at \(t^{n-1}\) | \(\epsilon^n\) | \(\epsilon^{n-1}\) | \(\eta^n\) |
|---|---|---|---|---|---|
| `native` | \(U_B^\star\) | \(U_B^\star\) | \(0\) | \(0\) | \(0\) |
| `full` | \(\widehat U_B^\star\) | \(\widehat U_B^\star\) | \(\epsilon^\star\) | \(\epsilon^\star\) | \(\tfrac32\epsilon^\star\) |
| `latest_only` | \(\widehat U_B^\star\) | \(U_B^\star\) | \(\epsilon^\star\) | \(0\) | \(2\epsilon^\star\) |
| `older_only` | \(U_B^\star\) | \(\widehat U_B^\star\) | \(0\) | \(\epsilon^\star\) | \(-\tfrac12\epsilon^\star\) |

### 4.1 Initial iterate

Use exactly the same initial iterate for the \(n+1\) nonlinear/dual-time solve in all four cases:

\[
U_{B,0}^{n+1}=U_B^\star.
\]

This is essential for the initial-residual comparison.

### 4.2 Physical-step convergence

Advance exactly one physical BDF2 step and converge it tightly. The final nonlinear/dual-time residual must be well below the initial history-forcing residual and below the magnitude needed to distinguish the cases.

Use identical:

- physical time step;
- inner-iteration limit;
- CFL strategy;
- linear-solver settings;
- convergence tolerances;
- initial iterate;
- coefficient sampling.

Do not permit method-dependent solver settings.

### 4.3 Why the `older_only` case is indispensable

The `older_only` restart has

\[
\epsilon^n=0,
\qquad
\eta^n=-\frac12\epsilon^\star\neq0.
\]

A nonzero first-step response in this case directly proves that the error in the latest state alone cannot characterize a BDF2 restart. This is the cleanest direct validation of the paper's two-history argument.

---

## 5. Exact initial-residual verification

Before performing nonlinear iterations, evaluate and export the complete target residual vector at the common trial state \(U_B^\star\) for every history pair.

For each perturbed case, compute

\[
r_{\mathrm{diff},0}
=
\Phi_B(U_B^\star;U_{\mathrm{case}}^n,U_{\mathrm{case}}^{n-1})
-
\Phi_B(U_B^\star;U_B^\star,U_B^\star),
\]

and the predicted vector

\[
r_{\mathrm{pred},0}
=-\frac{1}{\Delta t}M_B\eta^n.
\]

Report

\[
e_{\mathrm{res,id}}
=
\frac{\|r_{\mathrm{diff},0}-r_{\mathrm{pred},0}\|}
{\|r_{\mathrm{pred},0}\|+\epsilon_{\mathrm{floor}}}.
\]

The sign convention in the code must be checked against the residual definition above. If the solver stores the negative residual, modify the comparison consistently and document it.

### Required exports

Export either the complete residual vectors or sufficient binary/CSV data to reproduce:

- the vector identity error;
- global and componentwise residual norms;
- the cosine of the angle between \(r_{\mathrm{diff},0}\) and \(r_{\mathrm{pred},0}\).

The residual identity is an algebraic implementation check. It should agree to roundoff or to the precision imposed by the exported data and residual assembly.

---

## 6. State norms and spatial compatibility

Use a volume-weighted norm consistent with the target finite-volume discretization:

\[
\|q\|_{M_B}=\sqrt{q^T M_B q}.
\]

Also report a normalized form, for example

\[
\|q\|_{M_B,\mathrm{rel}}
=
\frac{\|q\|_{M_B}}
{\|U_B^\star\|_{M_B}+\epsilon_{\mathrm{floor}}}.
\]

Calculate norms separately for:

- density;
- each momentum component;
- total energy;
- each turbulence/transition variable;
- the complete conservative state.

For each transfer method, report:

\[
\|\epsilon^n\|_{M_B},
\qquad
\|\epsilon^{n-1}\|_{M_B},
\qquad
\|\eta^n\|_{M_B},
\qquad
\|\delta^{n+1}\|_{M_B}.
\]

### Spatial-residual compatibility

At minimum, evaluate

\[
F_B(\widehat U_B^\star)-F_B(U_B^\star)
\]

and report its target-volume-weighted norm. This diagnostic measures how incompatible the latest transferred field is with the target spatial operator, independently of the BDF2 history combination.

Keep this quantity distinct from the exact history-residual forcing \(-M_B\eta^n/\Delta t\).

---

## 7. First-step response and superposition tests

After converging the first physical step, compute

\[
\delta_{\mathrm{case}}^{n+1}
=
U_{B,\mathrm{case}}^{n+1}
-U_{B,\mathrm{native}}^{n+1}.
\]

In the locally linear regime, the following relations should hold approximately:

\[
\delta_{\mathrm{full}}^{n+1}
\approx
\delta_{\mathrm{latest}}^{n+1}
+
\delta_{\mathrm{older}}^{n+1},
\]

\[
\delta_{\mathrm{latest}}^{n+1}
\approx
\frac{4}{3}\delta_{\mathrm{full}}^{n+1},
\qquad
\delta_{\mathrm{older}}^{n+1}
\approx
-\frac{1}{3}\delta_{\mathrm{full}}^{n+1}.
\]

Report the vector superposition defect

\[
e_{\mathrm{sup}}
=
\frac{
\|\delta_{\mathrm{full}}^{n+1}
-\delta_{\mathrm{latest}}^{n+1}
-\delta_{\mathrm{older}}^{n+1}\|_{M_B}}
{\|\delta_{\mathrm{full}}^{n+1}\|_{M_B}+\epsilon_{\mathrm{floor}}},
\]

and the two coefficient-ratio defects.

A large superposition error does not invalidate the history forcing identity; it indicates nonlinear response, limiter activation, or a transfer disturbance outside the local linear regime. If this occurs, run the optional amplitude sweep in Section 8.

---

## 8. Optional perturbation-amplitude sweep

To test the linear regime without generating new meshes, form scaled target states

\[
\widehat U_B^\star(\lambda)
=
U_B^\star+\lambda\left(\widehat U_B^\star-U_B^\star\right),
\]

with, initially,

\[
\lambda\in\{0.25,0.5,1.0\}.
\]

Check physical admissibility before writing each restart. Do not use a value of \(\lambda\) that creates non-positive density, pressure, energy, or invalid turbulence variables.

Repeat the four-history matrix. In a linear regime:

- \(\|\eta\|\) should scale linearly with \(\lambda\);
- \(\|\delta^{n+1}\|\) and the first-order force response should scale linearly with \(\lambda\);
- the superposition and coefficient-ratio defects should decrease as \(\lambda\) decreases.

This sweep is optional but highly useful if the full transfer disturbance is too nonlinear for the analytical ratios.

---

## 9. Aerodynamic-output response

For every case, record at each physical step:

- \(C_L\);
- \(C_D\);
- pitching-moment coefficient using the paper's established reference point and sign convention;
- nonlinear/dual-time iteration count;
- final residuals.

Define

\[
\Delta C_Q^{n+1}
=
C_{Q,\mathrm{case}}^{n+1}
-C_{Q,\mathrm{native}}^{n+1},
\qquad
Q\in\{L,D,m\}.
\]

### Immediate-response checks

For each coefficient, test

\[
\Delta C_{Q,\mathrm{full}}
\approx
\Delta C_{Q,\mathrm{latest}}
+
\Delta C_{Q,\mathrm{older}},
\]

\[
\Delta C_{Q,\mathrm{latest}}
\approx
\frac{4}{3}\Delta C_{Q,\mathrm{full}},
\qquad
\Delta C_{Q,\mathrm{older}}
\approx
-\frac{1}{3}\Delta C_{Q,\mathrm{full}}.
\]

Interpret drag carefully. If its native value or perturbation is close to the numerical noise floor, report absolute changes and uncertainty rather than unstable relative percentages.

### Surface diagnostics

For the first converged step, export:

- surface \(C_p\) for native and restarted target cases;
- \(\Delta C_p\) along the airfoil;
- skin-friction coefficient if the case is viscous;
- the location and magnitude of the largest surface discrepancy.

These data show whether a small global state defect is concentrated in a force-sensitive near-wall region.

---

## 10. Short-time relaxation after the restart

After the first converged step, continue each restarted target case for a common short window with no further mesh transfer. A practical initial window is 20--50 physical steps, provided it is long enough for the coefficient defect to decay, propagate, or reach a measurable maximum.

Record

\[
\Delta C_L(t),\qquad
\Delta C_D(t),\qquad
\Delta C_m(t),
\]

and the corresponding state norm \(\|\delta(t)\|_{M_B}\).

Report:

- first-step response;
- maximum response over the window;
- time of maximum response;
- decay or persistence at the end of the window;
- whether the force response is immediate or delayed relative to the initial state defect.

This is a relaxation/propagation test on the fixed target mesh. It is distinct from the dedicated spatially separated delayed-response experiment in Section 13.

---

## 11. Global-correction comparison

For paired raw and globally corrected NN/BAR states, use identical history configurations and solver settings.

Compare the effect of the global correction on

\[
\|\epsilon^n\|,
\quad
\|\eta^n\|,
\quad
\|r_{\mathrm{diff},0}\|,
\quad
\|\delta^{n+1}\|,
\quad
|\Delta C_L|,
\quad
|\Delta C_D|,
\quad
|\Delta C_m|.
\]

The global correction is successful at its stated task if the selected total integrals are restored. Do not infer that the restart disturbance or force response must decrease. The purpose of this comparison is precisely to test whether removal of the scalar global defect also removes the dynamically relevant spatial defect.

---

## 12. Optional linearized target-operator test

If the target Jacobian or an equivalent matrix-free linearized solver is available, solve

\[
\left(\frac{3}{2}M_B+\Delta t J_B\right)
\delta_{\mathrm{lin}}^{n+1}
=M_B\eta^n.
\]

Compare with the actual converged nonlinear response:

\[
e_{\mathrm{lin}}
=
\frac{
\|\delta^{n+1}-\delta_{\mathrm{lin}}^{n+1}\|_{M_B}}
{\|\delta^{n+1}\|_{M_B}+\epsilon_{\mathrm{floor}}}.
\]

Also compare the predicted linearized coefficient response

\[
\Delta C_{Q,\mathrm{lin}}
\approx g_{Q,B}^T\delta_{\mathrm{lin}}^{n+1}
\]

if a coefficient gradient or adjoint is available.

This is the most direct validation of the linearized equation in the paper, but it is not mandatory for the first publishable batch. The exact residual identity and mixed-history response matrix are mandatory.

---

## 13. Weakly unsteady extension

The steady experiment uses the same spatial defect at both history levels. It validates the BDF2 coefficients cleanly but does not test a general pair of non-collinear defects.

After completing the steady matrix, retain the fixed airfoil and apply a small sinusoidal inflow-angle or vertical-gust perturbation, for example

\[
\alpha_\infty(t)
=\alpha_0+\Delta\alpha\sin(\omega t),
\qquad
k=\frac{\omega c}{2U_\infty}.
\]

A possible starting point is \(\Delta\alpha=0.25^\circ\) and \(k=0.05\), but these are not mandatory values. Confirm that the response is approximately linear and sufficiently resolved in time. Use at least 100 physical steps per forcing period unless a temporal-convergence study supports a coarser resolution.

### Procedure

1. Run native source and target calculations to a repeatable periodic response.
2. Select at least eight phases over one period.
3. At each phase, transfer both source histories onto the target mesh.
4. Advance one fully converged target BDF2 step.
5. Continue for a common 20--50-step response window.
6. Repeat at identical phases for the selected interpolation methods.

### Required analysis

At each phase compute

\[
\|\epsilon^n\|,
\qquad
\|\epsilon^{n-1}\|,
\qquad
\|\eta^n\|,
\qquad
\|\delta^{n+1}\|,
\]

as well as the initial residual forcing and coefficient response.

Compare whether the first-step response is more consistently related to \(\|\eta^n\|\) than to \(\|\epsilon^n\|\). Perform the comparison phase by phase or include phase explicitly in any regression; do not blindly pool phases because the target Jacobian and aerodynamic sensitivity vary over the cycle.

The `older_only` steady experiment is already a categorical demonstration that \(\epsilon^n\) alone is insufficient. The weakly unsteady phase sweep provides the general quantitative validation for different history defects.

---

## 14. Dedicated delayed-propagation experiment

Run this only after the immediate fixed-airfoil restart study is complete.

Construct target meshes that are unchanged in the airfoil and near-wall region but differ in a localized upstream or far-field region. Transfer the same physical source state and identify the initial support of \(\epsilon\).

Continue on the target mesh and measure when the aerodynamic coefficient defect first exceeds the native-target noise floor. Compare the measured onset time with convective and acoustic travel-time estimates from the perturbed region to the airfoil.

This experiment tests spatially delayed propagation. If it is not performed, the manuscript should not present delayed propagation as a validated result; it should remain a theoretical implication or future development.

## 17. Acceptance criteria and decision gates

### Mandatory first-batch success criteria

The steady NACA study is considered a direct validation of the BDF2 framework if:

1. the initial residual-difference vector agrees with \(-M_B\eta^n/\Delta t\) to the numerical/export precision;
2. the `older_only` case produces a response distinguishable from the native-target noise floor;
3. the response changes sign consistently with the negative \(-\tfrac12\epsilon^\star\) history coefficient;
4. the first-step response is measured relative to the native target step, not the source trajectory;
5. the aerodynamic coefficient response is reported with the corresponding state and residual diagnostics.

### Stronger linear-regime validation

The linearized interpretation is supported if:

- state and force superposition defects are small;
- the \(4/3\) and \(-1/3\) response ratios are approximately recovered;
- reducing the perturbation amplitude improves those relations;
- the optional Jacobian prediction agrees with the converged response.

Do not impose an arbitrary universal tolerance before seeing the signal-to-noise ratio. Report the actual defects and compare them with native numerical noise and nonlinear-solver tolerance. As a practical target, a superposition defect below approximately 5--10% is already useful evidence for a CFD restart perturbation; substantially larger values require either an amplitude sweep or a nonlinear interpretation.

### Need for the weakly unsteady extension

Proceed to the periodic fixed-airfoil case if the paper is to claim that \(\eta^n\) predicts general BDF2 restarts with different history defects. The steady mixed-history matrix validates the algebra and response coefficients, but its physical source defect is the same at both time levels.

### Delayed-response claim

Either perform the spatially separated experiment in Section 14 or reduce the manuscript's delayed-propagation discussion to an unvalidated implication/future development.

## 18. Recommended execution order

1. Finish and document the native source steady solution.
2. Finish and document the independent native target steady solution.
3. Run the native target BDF2 noise-floor trajectory.
4. Generate all transferred target states.
5. Compute transfer norms and total-integral defects.
6. Run the four-history matrix for one representative method to validate the workflow.
7. Verify the exact initial-residual identity before launching the full matrix.
8. Run the four-history matrix for all methods.
9. Compute target-referenced state and coefficient responses.
10. Continue the short relaxation window.
11. Compare raw and globally corrected NN/BAR variants.
12. Run an amplitude sweep if the superposition relations are strongly nonlinear.
13. Integrate the resulting CSVs into the paper.
14. Only then begin the weakly unsteady phase sweep and delayed-propagation extension.

---

## 19. Scientific interpretation boundaries

- Exact global conservation does not imply a small BDF2 restart forcing or a small aerodynamic response.
- The exact residual identity validates the BDF2 history algebra, not the linearized state response.
- The mixed-history superposition tests validate the local linear-response assumption only when their defects are demonstrably small.
- A nonzero `older_only` response is direct evidence against a latest-state-only restart metric.
- The native target trajectory is the only valid reference for isolating the transfer-induced response.
- Do not describe delayed propagation as validated unless the spatially separated experiment is run.
- Do not claim that one interpolation method is universally superior from a single mesh pair; report the measured mesh, flow, and time-step conditions.
